# 样式规格

出处：https://mp.weixin.qq.com/s/60GDijbHktEFMI6ptp-pdw （2026-10-22 抓取原文 HTML，并在 390px 手机宽度下截图实测）。只借排版，不带原文内容和原账号的品牌素材。

色值和尺寸都在 `themes/default.json`，渲染脚本 `scripts/render_wechat.py` 按下表生成。改样式先改主题文件，结构性改动再改脚本，改完重跑 `scripts/selftest.sh`。

## 后台正文容器（不在片段里，粘贴后由公众号提供）

| 项 | 实测值 |
|---|---|
| 内容宽度 | 屏宽减左右各 20px（390px 屏为 350px） |
| 默认字号 | 17px |
| 默认颜色 | rgba(0,0,0,0.9) |
| 对齐 | 两端对齐 |
| 顶层块段后距 | 24px（新版编辑器统一加） |

预览页的字号、颜色、对齐同这个容器，所以片段里的 `2em` 行高按 17px 算，等于 34px，和原文一致。宽度照公众号网页版：2026-10-22 在 1440 宽的桌面浏览器实测参考文章，白底，正文栏 `max-width:677px` 居中，外层左右 padding 20px，标题 22px，正文 17px，图宽 645px。同一套规则在 390px 手机宽度下正好得到 350px 正文栏。用户先要求铺满浏览器，宽屏上图被拉虚、读着也不直观，当天改成和网页版同宽。网页版在 1440 和 1920 宽度下两侧都是白的；用户要求用色块把正文栏衬出来，预览页两侧改用微信界面的底灰 #EDEDED（网页里 weui 的 `--weui-BG-0`），正文栏保持白底。

## 组件

| 组件 | 原文做法 | 本 skill 的做法 |
|---|---|---|
| 正文段 | `section` 左右 margin 16px、行高 2em；里层 span 16px、字距 1px，不设颜色 | 照搬，另写段后距 24px，后台再加也一样 |
| 导语段（第一个小节之前） | 同上，行高 1.5em | 照搬；稿里没有小节时不分导语 |
| 重点句 | 加粗 + rgb(226,139,8)，整段或半句都有 | `**…**` 转成 `font-weight:bold;color:#E28B08` 的 span |
| 小节标题 | 壹伴模板：两张背景图（#196CF0 蓝色平行四边形 148×40、#FFEEC8 奶油色渐隐条 268×40），白色 24px「01」，#0052FF 18px 加粗标题，整体高 40px | 行内 CSS 重画：外层 `skewX(-15deg)` 的 flex 行，左块蓝底放白色编号，右条奶油色渐隐到白，顶边一段 64×4px 蓝条；文字反向 skew 摆正。高 40px，与原文一致 |
| 小节前空行 | `<section><br></section>` | 照搬 |
| 配图 | inline-block 容器，左右 16px，图宽 100% | https 地址直接出图；本地图片缩到最宽 1440、格式不变，以 base64 嵌进页面；找不到文件或 `--no-embed` 时出灰色虚线占位框。预览页图宽最多 677px，2 倍屏要 1354 像素。2026-10-22 以前还会把不透明 PNG 转成 JPEG（质量 88），公众号发给读者时还要再压一遍，截图里的字发糊，当天改掉；同日一度照公众号的 1080 缩图，预览页在 Mac 上被放大 1.25 倍，次日改回 1440 |
| 引用、小标题、列表 | 原文没有 | 引用：左侧 3px 蓝线 + 浅蓝底；`###`：17px 蓝色加粗；列表：带「·」的普通段落（公众号列表样式不稳） |
| 公众号名片、原创标 | 后台插件，不在正文 HTML 里 | 不生成，交付时提醒在后台添加 |

不用原文的两张模板图：那是壹伴编辑器的模板素材，图片挂在别人的素材库里，换号后可能失效，也不是我们的资产。

## 卡片版式（`themes/card.json`）

出处：一篇企业号文章，2026-10-22 在 390px 和 1920px 宽度下抓取正文 HTML 实测。组件照搬尺寸，颜色写进主题。

| 项 | 实测值 | 主题键 |
|---|---|---|
| 正文 | 15px，行高 1.85，字距 0.5px，段后 18px，左对齐，左右不留边 | `text_size` `line_height` `letter_spacing` `para_gap` `text_align` `side_margin` |
| 正文色 | #48484A | `text_color` |
| 强调色 | #6B4CF5（重点、编号、标题后半句、色条、收尾卡文字） | `accent` |
| 标题色 | #1D1D1F（小节标题前半句、提示框文字、标题卡） | `heading_text` |
| 小节标题 | 上边距 44px；编号 12px 加粗、字距 2px；标题 21px 加粗、行高 1.45，逗号处断两行，后一行强调色 | `heading_size` |
| 提示框 | 底色 #F3F1FE，左侧 3px 强调色条，右侧圆角 10px，内边距 16px 18px，15px 加粗，行高 1.8 | `callout_bg` |
| 底色框（列表、引用） | 底色 #F6F5FA，圆角 12px，14px，行高 1.75 到 1.8，列表项前「▸」11px 强调色 | `box_bg` |
| 收尾卡 | 参考文章是强调色实底、白字。用户嫌太重，2026-10-22 改成提示框的淡色底 #F3F1FE、强调色字，不带左侧色条；圆角 14px，内边距 26px 20px，16px 加粗居中，行高 1.9 | `callout_bg` `accent` |
| 标题卡 | 渐变底 #EFEBFD → #F8F6FE → 白，内边距 28px 20px 26px；标签行 12px 强调色、字距 2px；标题 24px 加粗；下面 36×3px 强调色短条 | `title_card` `title_card_label` `title_card_top` `title_card_mid` |

和参考文章不同的地方：
- 参考文章的段落用 `p`，本 skill 统一用 `section` 加 `span`，和默认版式一样。卡片版式的区块上也写字号，倍数行高才按 15px 算，不跟后台容器的 17px。
- 小节标题和收尾卡在最靠中间的逗号处断行，参考文章是手工断的；标题卡每个分句一行。收尾卡加了 `word-break:keep-all`，手机宽度下只在标点处折行，后台清掉这个属性时退回普通折行。
- 参考文章里还有「第一道线」药丸标签、系列目录、「关于演示」说明框、关键词胶囊，这些要额外的写法，稿件里用不上，没有做。

## 退化方式

后台清洗 CSS 时，各组件按下面退化，仍然可读：

| 被清掉的属性 | 结果 |
|---|---|
| `transform` | 斜角变直角，编号和标题照样并排 |
| `background-image` 渐变 | 标题条变成 #FFF6E3 纯色底，顶边蓝条消失 |
| `display:flex` | 编号块和标题条上下排列 |
