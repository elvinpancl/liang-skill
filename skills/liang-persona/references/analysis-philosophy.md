# 分析哲学与理论边界

## 使用时机

遇到以下情况时读取：

- 用户追问方法依据或专家哲学。
- 同一产品存在多个购买角色或多个看似相同的人群。
- 初稿只剩焦虑、成长、品质、控制感等抽象词。
- 需要判断身份跃迁是否成立。

理论用于提出问题，不替客户证据作答。对具体人群的应用结论仍按 `[结果已验证]`、`[相关性待验证]`、`[待验证]` 标注。

## 一条统一推理链

```text
环境与约束
  ↓
触发事件与旧办法失效
  ↓
用户想取得的现实进步
  ↓
产品带来的功能、心理与社会结果
  ↓
可能的目标身份与害怕身份
  ↓
可观察的购买、拒绝与使用行为
```

从左向右形成假设，再从右向左用行为证据校验。右侧没有证据时，不能只靠理论把身份动机补全。

## 视角一：Lewin 的场域思想

核心启发：行为要放在人与环境的关系中理解。相同职业、年龄或收入的人，面对不同约束和触发事件，会形成不同决策。

用于追问：

- 最近什么变化使他开始行动？
- 哪些环境约束让某些方案不可接受？
- 换一个场景，这种行为还会发生吗？

使用边界：

- 不从一次购买反推永久人格。
- 不把「某类人都怎样」当作场域分析。
- 处境解释不了行为时，保留多个竞争假设。

## 视角二：Jobs to Be Done

核心启发：用户在某个具体处境中借产品取得进步。分析单位是「处境中的任务」，不是人群标签或产品类别。

检查四股力量：

1. 现状推力：什么问题或机会让旧状态难以继续？
2. 新方案拉力：什么具体进步值得改变？
3. 新方案焦虑：购买、迁移或使用最怕什么？
4. 旧习惯黏力：现有替代方案为什么仍被保留？

用于区分：

- 兴趣人群与真正进入购买临界点的人。
- 表面购买同一产品、实际任务不同的客户。
- 高痛苦但无行动条件的人，与产品能够交付的核心客户。

使用边界：

- 不把「想变好」当作有效任务。
- 任务必须包含触发、约束、期望进步和当前替代方案。
- 不把创始人想解决的问题冒充客户正在雇用产品完成的任务。

## 视角三：Means-End Chain

核心启发：产品属性之所以有价值，是因为它产生后果，后果再连接到个人价值或社会意义。

使用阶梯：

```text
产品属性
  → 直接功能后果
  → 使用与决策后果
  → 心理或社会结果
  → 个人价值或身份意义
```

追问方式：

- 这个功能帮他具体做成了什么？
- 做成以后，哪种风险、关系或自我评价发生变化？
- 这件变化为什么对他重要？

使用边界：

- 每上升一层都要有原话、行为或选择证据。
- 连续追问不等于一定能抵达宏大价值。
- 便利、价格或习惯足以解释时及时停止。

## 视角四：Possible Selves

核心启发：人会受「希望成为的自己」与「害怕成为的自己」影响。产品有时承担身份桥梁，让现实行动看起来更接近某种自我。

用于追问：

- 他希望重要他人怎样评价改变后的自己？
- 哪个失败会让他觉得自己成了最不愿成为的人？
- 产品提供了什么可执行动作，使目标身份不再只是愿望？

使用边界：

- 身份变化必须连接具体行动，不写空泛的「更好的自己」。
- 买家、用户与受益者分离时，分别分析各自的可能身份。
- 一次低卷入购买通常不足以支持长期身份结论。

## 为什么不设一个万能心理答案

「对失控的恐惧」能解释部分生计、经营与风险型购买，无法解释所有消费。另一些决定可能由责任、归属、胜任、便利、仪式、审美或地位驱动。

分析时先找具体矛盾：

> 想得到什么，同时不愿失去什么。

再命名心理母题。名称必须由行为、取舍与异议共同支持，不能先选一个理论词再寻找佐证。

## 理论落地检查

一个可用结论应同时通过：

- **情境一致**：能解释为什么在这个时间点行动。
- **行为一致**：能解释已经尝试的办法和愿意付出的代价。
- **异议一致**：能解释最强购买阻力。
- **产品一致**：能解释为何选择这个产品，而非任意方案。
- **边界清楚**：能指出相似却不属于核心群体的人。
- **可被推翻**：明确什么新证据会迫使结论改变。

理论名称无需出现在用户答案中。用户需要的是可验证的理解，不是术语展示。
