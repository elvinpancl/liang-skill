# 环境预检

先检查现有环境，再把可用版本、依赖和运行方式写入任务书。

| 项 | 怎么查 | 要求与对策 |
|---|---|---|
| ffmpeg | `ffmpeg -version` | 要有 libx264、lavfi。2018 版能用，但缺 ffprobe 时脚本改用 ffmpeg 解码计帧；也可以在工程里放 npm 的 ffmpeg-static 和 ffprobe，放进 `tools/bin/` |
| Python 环境 | `<venv>/bin/python -c "import librosa, numpy, scipy, soundfile, matplotlib, PIL"` | 工程目录建 venv（`uv venv`），装 librosa、numpy、scipy、soundfile、matplotlib、pillow；剪映导出再加 `pyjianyingdraft==0.3.1`，取字体加 fonttools。装之前问用户 |
| HyperFrames CLI | `ls ~/.npm/_npx/*/node_modules/.bin/hyperframes` | 固定一个版本，在工程 `tools/bin/hf` 写包装脚本：禁用遥测（`HYPERFRAMES_NO_TELEMETRY=1`、`DO_NOT_TRACK=1`）和 skills 自动更新（`HYPERFRAMES_SKIP_SKILLS=1`），把工程的 ffmpeg 放进 PATH。不要用 `npx hyperframes` 现拉 |
| Codex CLI | `codex --version` | 全局版本读不了配置时，用 `npx -y @openai/codex@0.163.0` |
| Chrome | `/Applications/Google Chrome.app` | 渲染在沙箱外用它 |
| 外置盘 | `diskutil info <卷 UUID>` | 按卷 UUID 核对，不只看盘名；原曲、录屏只读 |
| 剪映 | 版本号、草稿库位置、进程名 | 先验证当前版本；草稿库位置查项目 SOURCE_OF_TRUTH.md |
| 字体 | `extract_fonts.py --brand <brand.json> --out 工程/assets/fonts` | 品牌字体是系统可下载字体时，路径因机器而异，脚本按文件名查找 |
| 采样率 | analyze_frames.py 要求能被 30 整除 | 44.1 kHz、48 kHz 都可以；别的采样率先问，不静默重采样 |

整片渲染：只跑 lint，不跑 `hf check`（会超时），`--workers 4`。耗时依素材、机器和版本变化，应先做小样测量。
