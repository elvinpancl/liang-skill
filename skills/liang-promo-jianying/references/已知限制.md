# 已知限制

剪映 Mac 11.4、pyJianYingDraft 0.3.1，2026-10 实测。剪映升级以后先跑 `smoke.sh` 再信这些结论。

| 限制 | 影响 | 怎么处理 |
|---|---|---|
| 剪映打开明文草稿后会升级并加密保存，单向 | 装进去、被剪映打开过的草稿，脚本再也读不了、改不了 | 每个版本用新草稿名生成；用户在剪映里改过的版本不要用脚本覆盖 |
| 草稿 platform 字段带本机设备标识（从草稿库里明文老草稿抄来） | 草稿目录发给别人，会带出这台机器的信息 | 对外只交渲染成片；要工程就在对方机器上重新生成 |
| 新机器上可能找不到明文老草稿抄指纹 | `mac_draft.macify` 会直接失败 | 在剪映里新建一个空草稿立刻退出，再试；还不行就停下问人，不要用无指纹实验模式 |
| 剪映是沙盒应用，只能访问自己的草稿目录 | 草稿引用外部路径的素材会报「暂无访问权限」 | 安装时 `mac_draft` 把所有媒体打包进草稿的 `Resources/`；图片、视频、音频都要走这一步 |
| 剪映字库里没有的字体，打包 ttf 不生效 | 品牌字体显示成默认字体 | `font_mode: system`，文字的 font_path 直接指向系统字体文件；ttc 按第 0 个字形渲染 |
| 用户在字体面板换过字体，就回不到系统字体 | 改字体后无法恢复品牌字体 | 只改文字内容不会丢字体；真要换回来就重新生成草稿 |
| 换电脑时系统字体路径不同 | 文字显示默认字体 | 重新生成；或品牌包改 `library` 模式，用字库里的替代字体 |
| 部分转场（如「横移模糊」）库里标为 VIP | 导出时可能要会员 | `build_manifest.json` 的 transitions 记了 `is_vip`；交付时提示一句 |
| 剪映里 3D 动效、粒子、光效做不出来 | 这些段只能烘焙成视频 | 用 HyperFrames 或 HTML 渲染「底片」，`cut_segments.py` 切出来放主轨；其余能原生的都原生 |
| 草稿引用的素材在本机 | 素材挪走或改名，剪映会缺素材 | 安装后会打包进 Resources；安装前 staging 里引用的素材不要动。项目索引里写清楚 |
| 安装时剪映不能在运行 | 剪映会覆盖注册表 | `jy_install.py` 检测到 `VideoFusion-macOS` 或 `JianyingPro` 就拒绝 |
