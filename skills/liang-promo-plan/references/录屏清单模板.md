# 录屏清单模板

下面的示例行都是虚构的，只示范写法。

## 页面盘点表

| 页面 | 路径 | 看到了什么 | 有没有数据 | 状态 |
|---|---|---|---|---|
| 知识库 | /tenant/docs | 新建、上传、摘要、权限 | 有 | 有数据 |
| 智能体 | /tenant/agents | 生成配置、发布审批 | 没有 | 看到 |
| 租户设置 | 只在语言包里见过 | | | 待核实 |

状态只能是这三种之一。「待核实」的页面不能进镜头表。

## 系列地图

| 集 | 观众问题 | 画面里要出现的结果 | 页面 | 状态 |
|---|---|---|---|---|
| EP01 | 管理员怎么把团队和模型准备好 | 成员按身份看到各自的入口 | 租户向导、成员管理 | 有数据 |
| EP02 | 怎么让 AI 依据公司资料回答 | 回答带出处，点开能回到原文 | 知识库、新建任务 | 需造数据 |

## 身份表

| 身份 | 用哪个账号 | 画面上怎么认 | 负责哪几集 |
|---|---|---|---|
| 租户管理员 | 演示公司的管理员账号 | 页眉显示演示公司名 | EP01 到 EP05 |
| 平台管理员 | 平台运营账号 | 侧边栏多出平台审核、平台运营两组菜单 | EP01、EP07 |

## 单集镜头表

**EP03 做一个自己的助手**（前置条件：知识库已建好）

| 镜头 | 身份 | 页面 | 操作 | 画面里要出现的结果 | 标注 |
|---|---|---|---|---|---|
| S01 | 租户管理员 | 新建任务 | 不挂助手直接问一次 | 回答没有统一口径，作为对照 | |
| S02 | 租户管理员 | 智能体 | 用业务描述生成配置 | 系统提示词和知识库自动填好 | |
| S03 | 租户管理员 | 审批管理 | 申请发布并审批 | 审批单上能看到提示词全文 | 新增 |
| S04 | 租户管理员 | 知识库 | 删除一份资料 | | 不录，口播带过 |

## 开录前统一准备

| 项 | 要求 |
|---|---|
| 窗口 | 固定浏览器窗口大小和缩放比例 |
| 界面 | 关掉公告条，统一主题、语言和界面密度 |
| 身份 | 按身份表准备好账号，切换身份的镜头单独录一段 |
| 敏感信息 | 录屏时不刻意回避，剪辑时统一打码 |
| 等待 | 生成和处理的等待段剪辑时加速，并标注加速 |
| 命名 | 原片按「镜头号 + 内容」命名，例如 S03申请发布.mp4，录完对照时能直接对上 |
