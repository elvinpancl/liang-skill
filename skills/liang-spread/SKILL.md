# liang-spread

解释一段内容如何进入受众情绪，并把解释转成后续选题和表达方向。

## 边界

- 可分析已发布内容、对标样本、用户稿件或话题片段。
- 重点是传播心理机制和情绪频道，不评价内容好坏。
- 不预测平台流量、完播率、点击率或推荐量。
- 发布前要判断稿件该怎么调整，转 `/liang-resonate`。
- 要找段落断点和口播卡点，转 `/liang-content-logic`。

## 准备

接收粘贴文本或文件路径。实际表现、评论或受众信息可以作为补充证据，但缺失时仍可做文本解码；此时必须把受众描述标为推断。

定位 `liang-content` 共享核心并读取 `references/resonance-framework.md`。

## 工作流

### 1. 建立文本证据图

先摘出：

- 内容对谁说话。
- 它替谁命名了处境或情绪。
- 它把问题归因给什么。
- 它要求受众接受、拒绝或改变什么。

只摘文本能支持的内容，不先解释。

### 2. 逐维解码

严格按共享框架分析五个固定维度，不增加自创理论：

1. 沉默解除。
2. 满足动机。
3. 内容采用的问题框架和立场。
4. 传播入口。
5. 信念结构。

每一维都写：

- 判断。
- 文本证据。
- 从证据到判断的推导。

没有证据就写「文本不足」，不能用直觉补齐。

### 3. 综合情绪频道

从五维交叉推出：

- 核心情绪：受众被激活的主要情绪及其现实处境。
- 有效立场：内容站在哪一群人的哪一边，如何定义问题。
- 传播载体：谁会最先转发，转发是在表达什么身份或态度。
- 延展空间：同一情绪下还能继续追问的具体问题。
- 漂移风险：哪些角度会让内容从代言变成说教，或破坏现有立场。

综合结论必须注明来自哪些维度。

### 4. 生成内容接力包

输出给后续 `/liang-content-seed` 使用的简短接力信息：

- 保持的核心情绪。
- 保持的表达立场。
- 可继续深挖的三个问题。
- 应避免的立场漂移。

默认只输出，不写入用户项目。用户明确要求沉淀时，再由用户指定写入位置。

## 输出

```markdown
## 传播情绪解码

### 文本证据图
- 对谁说：……
- 命名了什么：……
- 如何归因：……
- 希望受众做什么：……

### 五维解码
| 维度 | 判断 | 文本证据 | 推导 |
|---|---|---|---|

### 综合结论
- 核心情绪：……
- 有效立场：……
- 首批传播者：……
- 传播动机：……
- 漂移风险：……

### 内容接力包
- 保持的情绪：……
- 保持的立场：……
- 下一步问题：1. … 2. … 3. …
- 避免：……
```

传播结构只能说明内容具备哪些心理入口，不能据此宣称它一定会火。
