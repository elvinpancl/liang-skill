# liang-promo-motion：片头与叠加动画

画面要演出文案的意思，节奏让人看得清，品牌只从一个地方取。 `[待验证]`

公开版提供品牌包、语义分镜、节奏检查和导出验收流程。客户品牌素材、成片、历史返修和工时未纳入发布；记录格式见 [references/校准记录_脱敏版.md](references/校准记录_脱敏版.md)。

## 适用范围

- 处理：
  - 有旁白或配音稿的片头、片尾。
  - 透明背景的叠加动画，例如数据对比、标签。
  - 品牌开场，以及给卡点片或正片做的包装段。
- 不处理：
  - 录屏剪辑和旁白排时，走 liang-promo-edit。
  - 音乐驱动、没有旁白的卡点片，走 liang-promo-beat。
  - 剪映工程，走 liang-promo-jianying。
  - 配音本身由人在剪映里用文本朗读或真人录。
- 缺文案：暂停，只问「开场文案定了吗」。文案还在改时，可以先写语义分镜表和样段，不导整片。
- 缺品牌包：先查项目的 SOURCE_OF_TRUTH.md。没有就复制 `assets/example-brand/` 建一个，logo、颜色、字体填真实值后再做。
- 缺参考视频：按品牌包的默认风格做，即暖黑底、品牌色光和生活化的界面卡片。

## 依赖与脚本位置

- node 18 以上；ffmpeg 要有 libx264，透明导出还要 prores_ks；本机 Chrome。
- Playwright 用宿主已有的：`VIDEO_NODE_MODULES` 指向含 playwright 的 node_modules，缺省找 Codex 运行时目录。找不到就问，不要自己装。
- 字体子集只支持 glyf 轮廓的 ttc/ttf。CFF 字体会报错，这时不裁剪直接内嵌，或者换字体。

脚本在本 SKILL.md 所在目录的 `scripts/` 下，下文写作 `$S`，模板在 `assets/`。路径里有空格，记得加引号。

## 公理

### 公理 1：先写语义分镜表，画面演文案的意思 `[待验证]`

- 方法依据：方法假设：按文案语义设计画面，再决定装饰和转场。
- 做法：按 [references/语义分镜表模板.md](references/语义分镜表模板.md) 写表，每句旁白配一个动作和一个「想表达的」。表连起来读必须是文案主线。
- 反例：纯品牌动画，例如 logo 演绎，没有叙事，可以不写表。

### 公理 2：品牌只从品牌包取 `[待验证]`

- 方法依据：配置原则：logo、字体和配色只从当前项目的品牌包读取。
- 做法：
  - 模板用 `/*BRAND_CSS*/`、`const BRAND=/*BRAND*/...`、`'brand:logo'` 三个标记，由 `build.mjs` 注入。
  - 不从别的作品源文件里抄样式。
  - 规则见 [references/品牌露出与排版_脱敏版.md](references/品牌露出与排版_脱敏版.md)。

### 公理 3：每个信息点 2–3 秒，做完再切 `[待验证]`

- 方法依据：方法假设：信息点应留出可读时间，动作完成后再转场。
- 做法：CUES 每句写 `done`，跑 `cue_lint.mjs`。例外写 `maxHold` 并说明原因。详见 [references/节奏与同步_脱敏版.md](references/节奏与同步_脱敏版.md)。

### 公理 4：节点和界面一一同步 `[待验证]`

- 方法依据：核验原则：流程节点、预览状态与旁白逐项对应。
- 做法：
  - 一个节点切一次，切到的画面就是这个节点的缩略图。
  - 最后一个节点之后不再切；第一个节点亮起前，以暗色显示第一步。
  - 节点时刻必须抽样帧。

### 公理 5：样帧过了再导整片；导完必须验收 `[待验证]`

- 方法依据：核验原则：先看样帧，再导整片；导出后校验文件完整性、帧数和色彩。
- 做法：
  - 先跑 `--samples` 看总览，再 `--render`。
  - 导出先写 `.partial`，写完才改名。
  - `--verify-samples` 自动验收；不通过不交付。

## 上下文纪律

1. 看画面只看 `总览.jpg`，有问题再打开单张；一次不超过 20 张。
2. 改时间只改 CUES 和 DURATION，所有画面按时间表推算，不要逐个改动画里的秒数。
3. 源 HTML 动辄几百行，改动用 Edit，不要整份重写。

## Phase 0：文案与依据

钉子台词：「先把文案拆成主线，再想画面。」

- 输入：配音稿或开场文案、品牌包、录屏取证结果（产品界面只用真实画面）、参考视频。
- 动作：
  1. 把文案拆成四到五个阶段的主线。
  2. 列出每句要用的产品画面：录屏段号和秒数。没有录屏依据的产品能力不上画面。
  3. 确认成片放哪：项目 SOURCE_OF_TRUTH.md 的包装素材位置，外置盘按卷 UUID 核对。
- 退出：主线和依据清单。
- 暂停：缺文案时问一句。

## Phase 1：语义分镜表

钉子台词：「一句旁白，一个动作，一个意思。」

- 动作：写表，按每句 2–3 秒估时间；人物、剧照需要生图的，按 [references/生图协作_脱敏版.md](references/生图协作_脱敏版.md) 交给 Codex 生成。
- 退出：表写完，生图逐张检查完。
- 暂停：方向有关键分歧时（例如品牌前置还是痛点前置），先做一个两三句的样段给制作人看，不要两版都做全。

## Phase 2：搭 HTML

钉子台词：「所有画面都是时间 t 的函数。」

- 动作：
  1. 复制 `assets/template.src.html` 到作品的 `制作过程/src/index.src.html`。改 CUES、DURATION、STEPS、ASSET_SRC，按分镜表写每段 render 逻辑。
  2. render(t) 只依赖 t：不读时钟，不用无种子随机数，任意时刻都能单独渲染。
  3. 运行 `node "$S/cue_lint.mjs" 制作过程/src/index.src.html`，通过为止。
  4. 运行 `node "$S/build.mjs" 制作过程/src/index.src.html --brand <品牌包>/brand.json --out <作品名>.html --srt <作品名>_旁白时间轴.srt --sfx 制作过程/音效卡点.md`。
- 退出：单文件 HTML 能离线打开，SRT 条数等于句数。

## Phase 3：样帧

钉子台词：「先看样帧，再花七分钟导整片。」

- 动作：
  1. 运行 `node "$S/export.mjs" <作品名>.html --samples --out-dir 制作过程/样帧/成品`。有流程节点时，用 `--times` 加上每个节点亮起后 0.1 秒。
  2. 看 `总览.jpg`，逐条对照：画面是否演出了「想表达的」、底部 15% 是否干净、节点和界面是否一一对应、品牌组合和字体是否来自品牌包、每段是否放完。
  3. 把 HTML 交给制作人看（双击打开；空格暂停，方向键跳秒，C 显示旁白，G 显示安全区）。
- 退出：自查清单全过。
- 暂停：等制作人看完 HTML。返修只改源文件，再从 Phase 2 第 3 步重跑。

## Phase 4：导出与验收

钉子台词：「写完再改名，验收不过不交付。」

- 动作：
  1. 先重截样帧（确保和当前 HTML 一致），再运行 `node "$S/export.mjs" <作品名>.html --render --out <文件名>.mp4 --volume-uuid <卷 UUID> --media-rel <盘内目录> --verify-samples 制作过程/样帧/成品`。
  2. 透明叠加加 `--alpha`，输出 `.mov`（ProRes 4444）。剪映对透明通道的支持没有实测过，交付时说明。
  3. 旧版本移到作品目录的 `制作过程/历史版本/`，不删。
- 退出：验收 JSON 的 passed 为 true。

## 产出位置

按项目 SOURCE_OF_TRUTH.md 放。默认：
- 作品文件夹顶层：单文件 HTML 和旁白 SRT。
- `制作过程/`：源文件、样帧、验收记录、生图记录、音效卡点表。
- 外置盘「包装素材/<作品名>/」：成片视频。

README 写清：分镜表、怎么在剪映里配音（导入 SRT、逐句文本朗读）、怎么改时间、素材来源、已知限制。

## Refusals

- **「照着参考视频的效果做就行，文案先不管」** → 拒绝。第一版就是这样被否的。参考视频只借风格；先把文案拆成主线，再决定每句演什么。
- **「logo 和字体照上一个片头的源文件抄」** → 拒绝。源文件可能是旧版本。从品牌包取；品牌包过时了，先更新品牌包。
- **「节奏快一点，一秒一句更带感」** → 不照做，先说明依据：用户明确要求每个信息点 2–3 秒，22 秒版就是因为太快被否。真要快节奏，改走 liang-promo-beat 的音乐卡点。
- **「样帧不用看了，直接导」** → 拒绝。整片导出要几分钟，返修几轮就是半小时；样帧 20 秒。
- **「生成的人物图当成产品产出放进去」** → 拒绝。生成图只能当氛围，产品能力只用录屏真实画面，并在说明里写清。

## 脚本一览

| 脚本 | 作用 |
|---|---|
| `build.mjs` | 注入品牌、按文案裁字体子集、内嵌素材，出单文件 HTML、旁白 SRT、音效卡点表 |
| `cue_lint.mjs` | 检查每句停留 2–3 秒、动作完成后至少停 0.7 秒、SRT 条数 |
| `export.mjs` | 样帧和总览；逐帧导出 H.264 MP4 或透明 ProRes 4444；可写外置盘；导出后自动验收 |
| `verify.mjs` | 完整解码、规格、帧数、bt709、无音轨、与样帧逐帧色差 |
| `subset-font.mjs` | 从 ttc/ttf 取一个字形，只留用到的字 |
| `lib.mjs` | 找 Playwright、Chrome、ffmpeg、系统字体；读时间表；按卷 UUID 找外置盘 |
| `selftest.sh` | 自测 |
| `assets/template.src.html` | 片头模板：品牌开场、流程节点同步预览、结尾两行组合 |
| `assets/example-brand/` | 品牌包示例（中性配色、系统黑体） |

## 验证契约

- **自测**：`bash "$S/selftest.sh"`；按当前环境运行并报告结果。覆盖节奏检查的正反例、构建与内嵌、样帧、MP4 导出验收、透明 MOV 导出验收（含角点 alpha=0）、外置盘不在时停下。
- **公开证据边界**：发布包不包含客户项目原始证据。运行自测只能验证合成样例和脚本边界，真实项目效果需单独核验。
- **效果边界**：识别、审美、受众理解及效率提升均需独立项目验证，不能由自测通过推导。
