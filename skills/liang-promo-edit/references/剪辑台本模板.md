# 剪辑台本模板

剪辑台本是每一篇的唯一底稿：镜头怎么切、旁白说什么、包装怎么做，都写在这一张表里。
`build_roughcut.py` 按它切粗剪，`make_subtitles.py` 按它排字幕，复盘时也拿它和成片比。

下面的示例行都是虚构的，只示范写法。

## 表格

```markdown
# <篇名>剪辑台本

时长预算：全片上限 3:00；开场 27 秒、结尾 12 秒在粗剪以外，正文预算 2:21。
原片根目录：<路径>（切粗剪时用 --src 指过去）

| 序号 | 段落 | 身份 | 原片 | 入点 | 出点 | 速度 | 转场 | 放大 | 打码 | 旁白 | 音效 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 建资料库 | 租户管理员 | EP02/S2新建资料库.mp4 | 0:12.0 | 0:17.5 | 1 | 切 | 左上推 |  | 先建资料库／谁能看这批资料／建库时就定好了 | 点击 | |
| 2 | 上传 | 租户管理员 | EP02/S2新建资料库.mp4 | 0:48.0 | 0:52.0 | 1 | 叠化 |  |  | 资料按文件夹一次传上去 | 点击 | 上传等待已剪掉 |
| 3 | 审批 | 平台管理员 | EP03/S5c补录_退款审批.mp4 | 2:09.0 | 2:13.0 | 1 | 闪黑 | 右上 | 0.62,0.31,0.20,0.04 | 换到平台管理员／审批单上写着退款金额不能超过实付 | 唰 | 切身份，邮箱打码 |
| 4 | 执行任务 | 租户管理员 | EP05/S2执行.mp4 | 0:31.0 | 1:52.0 | 4 | 叠化 |  |  | @0.5 交给它一件完整的活／结论、材料、工单都有了 | | 等待 4 倍速 |
```

## 每一列怎么写

| 列 | 写法 | 谁用 |
|---|---|---|
| 序号 | 从 1 起的整数，不重复。切出来的片段按它命名 | 切粗剪 |
| 段落 | 两到六个字，说这一镜头在讲什么 | 片段命名、包装清单 |
| 身份 | 多身份产品必填，例如租户管理员、平台管理员、游客。和上一行不同时，转场写闪黑，旁白点一句身份 | 人看 |
| 原片 | 相对原片根目录的路径，也可以写绝对路径 | 切粗剪 |
| 入点、出点 | 原片里的时间，写「1:05.5」或「65.5」。从镜头索引的「建议保留」起步，按画面调 | 切粗剪 |
| 速度 | 1、2、4。打字段 3 到 4 倍，进度条和执行过程能看出在动就用 4 倍；完全静止的等待直接剪掉 | 切粗剪 |
| 转场 | 进入这一镜头的方式：切、叠化、闪黑。同一段落里跳过等待用叠化；换身份、换大段落用闪黑 | 预览片、剪映 |
| 放大 | 左上、右上、左下、右下、中心、上半、下半、左半、右半，或「x,y,w,h」比例坐标；末尾加「推」表示开头 0.5 秒推近。只出备选片段，不烧进主片段 | 放大备选 |
| 打码 | 「x,y,w,h」比例坐标，多处用分号隔开；后面加「@0:58-1:00」表示只在原片这段时间里打。直接烧进主片段 | 切粗剪 |
| 旁白 | 一句一行，用「／」隔开，每句 8 到 14 字。句首写「@1.5 」表示镜头开始后 1.5 秒开口，用来对齐结果出现的时刻 | 排字幕 |
| 音效 | 点击、键盘、翻页、唰，可以不写 | 包装清单 |
| 备注 | 给人看的说明，例如等待已剪掉、切身份 | 人看 |

坐标从镜头索引的识别结果里抄：索引 JSON 里每个文字块都有 x、y、w、h，原点在左上角，单位是画面宽高的比例。
打码框比文字块各边放宽 0.01 左右更稳。

## 写台本的顺序

1. 先按时长预算定段落：每段一句观众问题，再给每段分秒数。
2. 每段从镜头索引里挑动作段，入点从「建议保留」起步。一段只留结果出现的那几秒，等待剪掉。
3. 把标了要打码的动作段写进打码列，坐标抄索引里的识别结果。
4. 粗剪切出来以后再写旁白列，不在切之前写。
5. 改旁白不用重切，直接改这一列，再跑 `make_subtitles.py`。
