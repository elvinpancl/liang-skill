# 校准记录（公开脱敏版）

公开版不附带客户成片、个人反馈或历史项目指标。默认值仅为可配置的起点，不代表效果保证；使用者应在自己的项目中试录、测量并调整。

## 口径

- 字数去掉空格与标点，英文字母和数字各算一个字。
- 旁白沿用率按字数计算；正文与开场、结尾分开记录。
- 镜头覆盖率与编辑时长均说明测量范围，复制工程的累计时长不能当本片新增时长。

## 当前默认值

`make_subtitles.py` 和 `render_slides.py` 不给 `--rate` 时读取本表。数值是公开版可调起点，应根据实际配音校准。

| 参数 | 值 | 依据 |
|---|---|---|
| `make_subtitles.py --rate` | 4.7 字/秒 | 初始参数，试录后调整 |
| `render_slides.py --rate` | 5.7 字/秒 | 初始参数，试录后调整 |
| 正文能写多少字 | 预算秒数 × 4 | 初始预算 |
| 共用开场加桥接 | 27 秒 | 初始预算 |
| 解法页 | 12 秒 | 初始预算 |
| 叠化 | 0.5 秒 | 初始参数 |
| 索引取帧间隔 | 4 秒 | 初始参数，应补查遗漏 |

## 止损线

某一步连续两个项目低于约定目标，或无法降低返工时长时，重新评估该步骤并记录原因；必要时降级为建议。阈值由具体项目约定，不把初始参数当通用效果定律。
